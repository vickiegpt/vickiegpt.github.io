Note: This page uses the x86_64 QEMU wasm assets and range-backed `/about/bzImage` plus `/about/qemu.img`. ACPI-backed QEMU CXL devices can be re-enabled with `?acpi=on&qemu_cxl=1`.

            
Boot: Default boot uses trimmed systemd and keeps CXL initialization. Add `fast_login=1` only for a direct `/bin/sh` debug shell, or `fast_boot=0` to restore the guest defaults.

            
Network: The browser network stack is connected through `-netdev socket` and the c2w fetch proxy. Inside the guest, use `http_proxy`/`https_proxy` with `http://192.168.127.253:80` for outbound HTTP(S).
