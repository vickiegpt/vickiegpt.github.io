Note: This page uses the x86_64 wasm32 TCG QEMU assets and range-backed `/about/bzImage` plus `/about/qemu.img`. ACPI-backed QEMU CXL is enabled by default; use `?cxl=off` only for non-CXL debug. `qemu_core=fpcast` is only a compatibility fallback.

            
Boot: Default boot opens `/init` from the tiny initramfs with host-backed RTC and CXL ACPI on. Browser Type2 uses QEMU shared-pool transport; do not use `acpi=off` with CXL.

            
Network: The browser network stack is connected through `-netdev socket` and the c2w fetch proxy. Inside the guest, use `http_proxy`/`https_proxy` with `http://192.168.127.253:80` for outbound HTTP(S).
